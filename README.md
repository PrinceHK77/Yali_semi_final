# 👥 Persona Management Software

![image](https://github.com/user-attachments/assets/c9d247a3-a41a-457e-a866-ee5f9a903f33)

A robust Persona Management System designed to organize and streamline interactions across different personas — including employees, vendors, and customers. With built-in AI capabilities and advanced web development practices, this software enables clear hierarchy, efficient scheduling, and secure document handling.

---

## 🌐 Overview

The Persona Management System provides:

- 🧑‍💼 Persona Definition: Employees, Vendors, Customers  
- 🏢 Role & Hierarchy Mapping  
- 📅 Activity & Timeline Tracking  
- 📂 Document Workflow & Transaction Management  
- 📧 Integrated Mailing System  
- 🗓️ Smart Meeting Scheduling  
- 🧠 OCR-based Document Parsing using AI

---

## 🛠 Tech Stack

| Layer           | Technology              |
|----------------|--------------------------|
| Frontend       | React.js                 |
| Backend        | Node.js / FastAPI (planned) |
| Database       | PostgreSQL               |
| AI Integration | Optical Character Recognition (OCR) |
| Tools          | Frappe API · Redmine · SMTP Mailer |

---

## 📁 Features

- 🎯 Persona Creation & Profile Management  
- 🔗 Relationship Mapping (Manager–Employee, Vendor–Project, etc.)  
- 🔒 Role-Based Access Control  
- 📃 Smart Document Uploads + AI Parsing  
- 🕒 Activity & Timeline Dashboard  
- 📬 Email Notification System  
- 📆 Auto-Scheduler for Meetings

---

## 🧠 AI-Enhanced Capabilities

- 📑 OCR: Convert scanned docs into searchable and storable data  
- 🤖 NLP (Planned): Understand responsibilities and extract structured data  
- 📈 Analytics (Planned): Track persona efficiency & engagement
